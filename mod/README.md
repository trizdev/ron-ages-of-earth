# mod

Mod files follow the game's mods folder layout (`Data/*.xml`, `tribes/*.xml`, `.tga` textures, icons).

## Current content: v0.1 (all in-game text)

Copies of game files where only display text was changed (hashes, IDs and structure untouched):

- `Data/typenames.xml`, `Data/string_lookup.xml`, `Data/translated_strings.xml`, `Data/alternatenames.xml`, `Data/help.xml`: eras, units, buildings, wonders, resources, technologies, governments, biomes and scenery animals.
- `tribes/*.xml` and `*.xml.9`: short nation names for the nation list.

Tested in game on 2026-10-18. Art is still the original game art.

To test locally, copy `Data` and `tribes` into `Rise of Nations/mods/Ages of Earth v0.1/` and enable it under Tools & Extras > Steam Workshop.
